# Trigger Map

Use this map to route user requests to the correct formation surface.

| User signal | Use file | Output |
|---|---|---|
| "We need to stand up a PMO/PPMO/EPMO" | ppmo-formation-intake.md | Formation intake summary |
| "Nobody knows who approves what" | decision-rights-model.md | Decision-rights matrix |
| "We have hundreds of initiatives" | portfolio-taxonomy.md | Portfolio taxonomy and baseline fields |
| "Everything comes in through side channels" | intake-model.md | Intake workflow and minimum fields |
| "Our steering committee is ineffective" | governance-council-design.md | Council design and cadence |
| "Executives ask for status but not decisions" | reporting-model.md | Reporting model and executive views |
| "We need to get this moving" | thirty-sixty-ninety-plan.md | 30/60/90 formation roadmap |
| "Prepare the final package" | output-templates.md | Formation package |
| "Where does this go next?" | handoff-rules.md | Downstream handoff brief |

## Stop conditions

Pause and ask for confirmation when the proposed PPMO scope crosses business units without named executive sponsorship, decision rights are implied but not confirmed, reporting claims require data that does not exist, or the user asks the system to approve org design, funding, risk acceptance, staffing, or executive decisions.

## Redirect conditions

- Active work intake triage: hand off to Portfolio Intake and Readiness Triage System.
- Portfolio scoring: hand off to Portfolio Prioritization Scoring Agent.
- Executive review packet: hand off to Executive Portfolio Review Pack Builder.
- Weekly decisions/actions/risks follow-through: hand off to PMO Governance Operations Log.
