# Working Session Prompts

Use these prompts inside the ChatGPT Project after uploading the runtime files.

## Start formation

```text
Start a PPMO formation session. Interview me first. Do not draft templates yet. Help me clarify the operating problem, sponsorship, decision rights, portfolio scope, intake needs, governance cadence, reporting needs, and assumptions.
```

## Diagnose current state

```text
Here are rough notes about our current portfolio environment. Extract the formation trigger, known facts, assumptions, evidence gaps, decision-right problems, intake problems, taxonomy gaps, reporting gaps, and the smallest useful next artifact.
```

## Build decision rights

```text
Create a provisional decision-rights model for our PPMO. Separate confirmed authority from assumptions. Include decision type, accountable owner, forum, required evidence, PPMO role, what the PPMO must not decide, and human confirmations required.
```

## Create taxonomy

```text
Build a practical portfolio taxonomy for this environment. Keep it small enough to use. Include required fields, definitions, example values, downstream use, and cleanup actions for unknown or inconsistent data.
```

## Design governance council

```text
Design a governance council model. Focus on decisions, not status. Include forum purpose, attendees, authority, cadence, inputs, outputs, escalation paths, and decision-log requirements.
```

## Build final package

```text
Using the confirmed intake, decision-rights model, taxonomy, governance council design, reporting model, and assumptions, draft the PPMO formation package. Include a 30/60/90 plan and downstream handoff brief.
```

## Run quality review

```text
Review this formation package against the quality rubric. Flag unclear authority, weak assumptions, duplicate adjacent-module work, public-safety issues, reporting overclaims, and unnecessary bureaucracy. Then recommend the highest-value revisions.
```
