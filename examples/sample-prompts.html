PPMO Formation Kit — Sample Prompts

1. Start the formation workflow

Start a PPMO formation session using this synthetic scenario. Do not draft templates first. Diagnose the operating problem, scope, decision-right gaps, intake gaps, taxonomy gaps, governance cadence needs, reporting needs, and human confirmations required.

2. Build the decision-rights model

Create a provisional decision-rights model for NimbusWorks. Separate confirmed authority from assumptions. Include decision type, accountable owner, forum, required evidence, PPMO role, what the PPMO must not decide, escalation trigger, and human confirmation required.

3. Create the taxonomy and intake model

Build a practical portfolio taxonomy and intake model for the 500-initiative environment. Keep fields minimal. Include intake states, minimum fields, routing outcomes, and downstream handoffs.

4. Design governance cadence

Design a governance council model for CIO/CFO/COO tradeoffs. Focus on decisions, not status. Include forums, cadence, attendees, inputs, outputs, escalation paths, and decision-log requirements.

5. Produce the formation package

Using the confirmed assumptions from the prior outputs, draft the PPMO formation package with operating charter, decision rights, taxonomy, intake model, governance council design, reporting model, decision-log pattern, 30/60/90 plan, and handoff brief.
