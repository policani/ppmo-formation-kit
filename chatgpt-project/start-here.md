# Start Here — PPMO Formation Kit

Use this project when an organization needs to establish, reset, or formalize a PMO, EPMO, PPMO, transformation office, or portfolio governance function.

## Start with the operating problem

Do not begin by creating templates. First clarify the operating problem the PPMO must solve.

Typical formation triggers:

- Too many initiatives and no trusted portfolio baseline.
- Unclear sponsor ownership.
- Intake happens through side channels.
- Executives disagree about priorities but lack a tradeoff forum.
- Delivery teams report status but leaders lack decision-ready views.
- Finance, technology, operations, product, and commercial leaders use different portfolio language.
- Governance meetings exist but do not produce clear decisions, actions, or escalation paths.

## First move

Ask for current-state evidence in six categories:

1. Portfolio scope: what work is included or excluded.
2. Decision rights: who can approve, defer, pause, fund, or escalate work.
3. Intake: how work enters today and what fields are missing.
4. Taxonomy: how work is classified today, if at all.
5. Cadence: which forums exist and what they decide.
6. Reporting: what leaders see and what remains invisible.

## Default output path

1. Formation intake summary.
2. Operating problem statement.
3. Boundary and charter draft.
4. Decision-rights model.
5. Portfolio taxonomy.
6. Intake model.
7. Governance council design.
8. Reporting model.
9. Decision-log pattern.
10. 30/60/90 plan.
11. Downstream handoff brief.

## Working rule

When information is missing, produce a provisional formation artifact with an explicit assumption register. Do not block progress waiting for perfect input, but do not hide uncertainty.
